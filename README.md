# Moonomat

**Parametric 3D for the web.**

Moonomat turns photos, drawings and descriptions into configurable 3D models for the web:
built by AI, refined by you, embedded on any page with two lines of HTML.

- **Try it:** [moonomat.com](https://moonomat.com)
- **Docs:** [moonomat.com/docs](https://moonomat.com/docs/)

## Repositories

- [**viewer-embed**](https://github.com/moonomat/viewer-embed): the `<moonomat-viewer>` element
  for embedding Moonomat designs in any web page (`npm i @moonomat/viewer-embed`)
- [**agent-cli-bridge**](https://github.com/moonomat/agent-cli-bridge): connects Moonomat's
  Design agent to Claude Code or Codex running on your machine
